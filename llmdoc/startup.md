# llmdoc 启动阅读顺序

新会话启动时按以下顺序阅读：

1. `llmdoc/must/build-system.md` — 构建管线与依赖关系
2. `llmdoc/must/workflow.md` — 日常开发流程速查
3. `llmdoc/overview/project-overview.md` — 项目定位与 fork 特色

按需深入：

- 修改 BaseBin 组件 → `llmdoc/architecture/basebin-components.md`
- 理解越狱执行链 → `llmdoc/architecture/jailbreak-lifecycle.md`
- 查看 dopamine 分支新特性 → `llmdoc/reference/dopamine-branch-features.md`
